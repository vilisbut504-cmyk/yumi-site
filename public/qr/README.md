# QR-код сайта ЮМИ

## Уже напечатанные QR (не менять)

Сканирование открывает короткий стабильный адрес:

- **Кириллица:** `https://юми-корм.рф/qr`
- **Punycode:** `https://xn----otbhfdlo0i.xn--p1ai/qr`

Страница `/qr` на сайте перенаправляет на главную с UTM-метками:

`/?utm_source=offline&utm_medium=qr&utm_campaign=launch_first_clients`

Файлы печати (не перегенерировать без необходимости):

| Файл | Назначение |
|------|------------|
| `yumi-main.png` | **Уже напечатанные** материалы — визитки, флаеры, наклейки |
| `yumi-main.svg` | Векторная копия того же legacy-URL `/qr` |

Так сохраняется аналитика кампании `launch_first_clients`.

## Новые QR-ссылки

Для новых офлайн-материалов используйте нейтральную кампанию:

`utm_campaign=yumi_offline`

URL:

- `https://юми-корм.рф/?utm_source=offline&utm_medium=qr&utm_campaign=yumi_offline`
- `https://xn----otbhfdlo0i.xn--p1ai/?utm_source=offline&utm_medium=qr&utm_campaign=yumi_offline`

Генерация новых файлов (не трогает `yumi-main.*`):

```bash
npm run qr:generate
```

Создаёт `yumi-offline.png` и `yumi-offline.svg`.

## Перед печатью

1. Отсканируйте QR с телефона (камера или приложение-сканер).
2. Убедитесь, что открывается сайт и вы попадаете на главную.
3. Проверьте на светлом и тёмном фоне макета — контраст должен быть высоким.

## Минимальный размер печати

Рекомендуется **не меньше 30×30 мм** на готовом макете. Меньший размер может ухудшить считывание.
